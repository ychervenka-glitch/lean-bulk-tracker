LEAN BULK — WORKOUT TRACKER

1. Для PWA завантажте всі чотири файли (index.html, manifest.webmanifest, icon.svg, sw.js) в одну папку на HTTPS-хостинг, наприклад GitHub Pages або Netlify.
2. Відкрийте URL у Safari на iPhone → Поділитися → На початковий екран.
3. Дані зберігаються локально в сховищі цього сайту на пристрої. Перехід до іншого чату не скидає чернетку. Дані не синхронізуються між пристроями; очищення даних сайту може видалити записи.
4. Регулярно натискайте «Резервна копія» і зберігайте JSON у Файлах/iCloud. Вкладка «Дані» дозволяє відновити JSON.
5. У першій версії додані підтверджені приклади історії Full Body A (29.10) і C (03.11), але НЕ повний архів. Для інших вправ з історією порожні дані вводяться вручну.
6. Для оригінальних ілюстрацій натисніть «Додати ілюстрацію» біля вправи. Зображення зберігається локально. Поки його немає, показано схематичну піктограму, не інструкцію з техніки.
7. Під час тренування позначайте галочкою кожен виконаний сет. Без галочки сет вважається планом і не входить до підсумків. «Р» означає розминку.
8. «Завершити · Звіт» формує текст для ChatGPT. Запис до Google Sheets НЕ відбувається автоматично.
9. Вага гантелі вказується за одну руку; тоннаж Incline DB Press та Lateral Raise множиться на 2. Для інших вправ тоннаж = кг × повторення.

ВАЖЛИВО: Не відкривайте index.html як локальний файл у переглядачі iPhone для довгострокового зберігання: використовуйте стабільний HTTPS URL.
